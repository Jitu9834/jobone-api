# jobone-api
Adzuna (India) job-search proxy for JobOne.

Set these in Render > Environment (never commit them):
- ADZUNA_APP_ID
- ADZUNA_APP_KEY
- ALLOWED_ORIGINS (optional, default https://jitu9834.github.io)

Test: /api/jobs?q=analyst&location=Pune
Jobs data by Adzuna (https://www.adzuna.com) — keep the attribution visible on the site.
